| Token | Hex | Use |
|---|---|---|
| `brand.primary` | `#E4FF54` | Primary actions, focus rings |
| `brand.ink` | `#0B0D0E` | Text on light, dark surfaces |
| `brand.mist` | `#F4F5F2` | Page background (light) |
| `status.danger` | `#E5484D` | Destructive actions only |

Never put primary on mist for text; contrast is too low. Use ink.
